## 🖥️ BLOQUE 2 — El proyecto (~60s)
**[PANTALLA — muestra el documento de Gamma con la portada y la fitxa del projecte]**

"Buscamines del Regne Malaït es un juego para móvil con ambientación modern-medieval.
Mantiene la mecánica clásica del buscaminas, pero añade una capa de estrategia y riesgo
completamente propia: la Ampliació Maleïda.

[Muestra la slide de la fitxa del projecte]

Cuando el jugador supera un tablero, tiene que tomar una decisión: recoge los puntos de forma
segura, o arriesga todo para multiplicarlos por dos, por cuatro o por ocho.
Si activa una trampa, pierde todo. De ahí viene el nombre: el Regne Malaït.

El juego tiene tres niveles de dificultad, cronómetro con bonus por rapidez y un ranking global
con dos clasificaciones. Todo diseñado para que cada partida sea diferente."

## 🖥️ BLOQUE 3 — Tecnologías y base de datos (~50s)
**[PANTALLA — muestra el README del repositorio en GitHub, desplázate lentamente]**

"A nivel técnico, el proyecto está desarrollado con HTML, CSS y JavaScript para el frontend
y la lógica del juego.

[Desplázate hasta la sección de la tabla de tecnologías]

Yo me he encargado también del diseño completo de la base de datos relacional en SQL,
con tres tablas principales: usuarios, niveles y partidas, conectadas entre sí con claves
primarias y foráneas.

[Desplázate hasta el bloque de código SQL]

Estas consultas son las que alimentan el ranking global, calculando tanto la mejor puntuación
por partida como la puntuación total acumulada de cada jugador.

Y todo el diseño visual lo prototipé primero en Figma, para tener claro cómo sería la interfaz
antes de escribir una sola línea de código."

## 🎥 BLOQUE 4 — Contribución personal (~40s)
**[CÁMARA — tono reflexivo, habla con convicción]**

"Mi rol dentro del proyecto ha sido triple: diseñador del juego, programador de la base de datos
y responsable de toda la interfaz y experiencia de usuario.

Eso significa que he tomado decisiones en todas las capas del proyecto: desde cómo se siente
el juego cuando lo tocas en pantalla, hasta cómo se estructuran los datos por debajo.

Lo que más me ha costado ha sido diseñar el sistema de puntuación de forma coherente,
especialmente el caso de las ampliaciones encadenadas. Pero encontrar esa solución es
de lo que más orgulloso estoy del proyecto."

- **Herramienta recomendada:** OBS Studio (gratuito) para combinar cámara + pantalla

  ten el README y el Gamma abiertos en pestañas separadas y listas
- **Tono:** No lo leas literalmente — úsalo como guía, habla con tus propias palabras
- **Velocidad:** Habla más despacio de lo que crees que debes. En vídeo siempre se va rápido
